# 优化类求解与验证决策表（optimization-playbook）

> 定位：**决策表与检查项**，不是范文模板。每条经验标注出处（华数杯 2026 C 题论文页码）与证据等级（A=数据复算支持 / B=理论推导支持 / C=定性论证）。
> 调用方：`competition-workflow` 阶段 0.5/1/2（优化类分支）与 `guozhan-paper` 3.5（写作检查）。
> 适用范围：大数据量（万级决策单元、长时域、多区域）优化类赛题。

## 2. 求解降级链决策表

每降一级，正文必须回答"为什么不能直接求"，并给出替代验证；替代验证未做则视为求解不完整。

| 规模 | 方法 | "为什么不能直接求"的判定条件 | 替代验证（必报） |
|---|---|---|---|
| 区域级、单日、千级任务 | MILP 求解器至最优 | — | 最优性间隙 = 0 声明 |
| 全时域、万级任务、含非线性项 | 贪心构造 + 局部搜索（GLS） | 全时域 MILP 决策空间过大；非线性来自负荷对已占任务的依赖 | 块级 MILP 重解对照，报间隙（华数杯表 7-3：3 个块间隙均为 0%） |
| 任务+储能联合、亿级变量 | LP 对偶分解 + 交替迭代 | 5 万任务 × 6 区 × 2407 时直接联合建模成亿级 MIP | 对偶变量扰动重解验证精确性；迭代收敛序列（华数杯 9.2：1826/148/83/19 万元递减）；终止准则（Δ消纳≤1MW 或 Δ成本<1万元 或回退） |

补充规则：
- 启发式解**不得宣称全局最优**；只能报"与块级全局最优间隙为 0"这类对照结论。
- LP 全局最优用对偶理论声明（华数杯 8.1），并说明"不存在局部最优问题"。
- 大任务计价修正：单任务功率增量（10-40MW）远超线性边际（MW 级）时，直接用对偶变量计价会低估成本，必须用分段公式修正（华数杯 (9.8)-(9.10) 的写法：先定义免费余量与外送余量，再写购电增量与外送挤占，最后给分段成本）。

## 4. 多目标前沿诊断流程

```
步骤1 权重端点扫描：λc×λl 取 6 个均衡点，全量求解，报扫描表（成本/碳排/延迟/迁移数）
步骤2 判读：
  前沿坍缩为单点 → 不急着换算法；找数据结构原因（华数杯：主时域仅 2 个购电小时、碳目标无作用对象；截面口径碳电同构）
    → 构造压力场景自证：新能源可用率 80%，前沿应显著扩展（华数杯表 7-4：SP0-SP4 三点拉开）
  前沿真实存在 → NSGA-II / ε-约束，报各目标分量贡献
步骤3 结论落点："前沿结构由数据结构决定（充裕时退化为单目标，紧张时产生真实权衡）"——这类结论要带证据（购电小时数、相关系数），不带证据不写。
```

## 6. 图表编号对账脚本思路（阶段 5 执行）

```text
1. 从 .tex 抽取正文全部引用：grep -oE '(图|表)[[:space:]]*[0-9]+(-[0-9]+)?'  → 集合 C
2. 从 .tex 抽取全部 caption：grep -E '\\caption\{'（figure/table 环境内）→ 集合 T（编号含章节前缀）
3. 判定通过条件：C ⊆ T 且 T 无缺号/重号；否则列出 (缺号表, 引用未定义表) 供逐条修正
```
华数杯 2026 翻车实录（对账必要性证据）：正文写"如图13所示：图11…图12…"实为图 6-1/6-2；"对比如表10所示"实为表 8-2；"图6.6"与"图6-3"编号格式混用——三处错误在单篇论文中同时出现，人工核对不可靠，必须脚本化。
