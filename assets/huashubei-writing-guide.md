## 二、图表规范（本次三大硬坑之一：图片不能图大字小）

### 2.1 图字号【本次最大硬坑】

- 现象：脚本以 `figsize=(15~20in)` + `dpi=200` 保存 PNG，插入 `width=0.92\textwidth`（≈14.7cm）后，图内 13–15pt 文字实际打印只有 **4–5pt**，评委看不清。
- 机理：最终字号 ≈ `matplotlib 字号 × (显示宽度 / 图物理宽度)`。图物理宽度 = 像素数 ÷ dpi。figsize 越大物理越宽、缩放比越小、字越小。**PIL 缩放像素无法拯救**（字号比例已栅格化），必须重新渲染。
- 规则：
  - `figsize 宽 ≈ 最终显示宽度`：0.92\textwidth（16cm 文本区 − 0.5cm ≈ 5.8 inch）；0.85\textwidth ≈ 5.4 inch
  - `dpi = 300`（清晰度足够，像素 ≈ 1700×N）
  - 图内字号 `base = 10.5~11pt`（与正文五号相当），标题 12–13pt
- 检查法：编译 PDF 后截图放大看坐标轴数字，或者算 `保存字号 × 缩放比 ≥ 9pt` 才合格。

### 2.2 三线表与表注

- 表格一律 booktabs 三线表；表格文字**五号**(10.5pt)；表题在表格上方居中，图题在图下方居中。
- 【特殊值硬坑】表格中的特殊数值必须加 `*` 标注 + 表注：
  - 负值：净收益/净外送收益/净外送功率（如 −45909 万元）→ 注"负号表示净外送收益"
  - 0 值：零购电、零碳排、区域无购电/无外送/储能闲置 → 注"0 表示……"
  - 负 R²（预测弱于用均值预测）→ 注"负值表示预测弱于序列均值，属低信噪比固有结构"
  - 恒定量（如新能源利用率不随调度变化）→ 正文必须如实说明
- 本次表注落点：表 6（问题三）、表 7（问题四场景）、附表 B4（R²）、B5–B7（分区指标）。

## 三、论文内容范式（来自《论文模版-说明版.docx》要点）

1. **摘要四段式**：起始（背景+研究问题，2–3 行）→ 主体（每题一段：问题简化/数学归类/建模思想/算法/模型特点/主要结果[定量]）→ 推广+灵敏度结论。摘要禁表格/公式/图。关键词 3–5 个（核心词+模型+算法型）。
2. **问题重述**：自组织词句，不整段照抄原题；不引用原题图表；≤1 页。
3. **问题分析**：可放问题重述后或假设符号后；**绝不能出现结果**（结果只在摘要和求解部分）；可含思路导图。
4. **模型假设**：5–8 条；三来源：题目自带/题目可推得/自己模型需要；不能有"模型正确性"类假设；罗列工整。
5. **符号说明**：三线表、约半页、不换页、带单位、不参与一般表格编号（本次单独表号无妨）。
6. **模型建立-求解-检验三段式**：每问都要有模型检验/验证闭环（本题：滚动验证、块级 MILP 最优对照、对偶最优、独立复算）。
7. **灵敏度分析**：必须做；本次做了参数 ±10% 扰动 + 弹性系数 0.948 + 七场景。
8. **模型评价与推广**：优点突出亮点、缺点要真实、推广半页即可。
9. **结果数字必须一条链**：从附件数据 → 程序输出 → 论文数字 → 附录复算，全部可复现、可核对（现代评卷看重可复现性）。
10. **AI 声明位置**：正文后、参考文献前（LaTeX 注意 \clearpage 不破坏）。

## 四、LaTeX/工具链踩坑记录

### 本次（2026-08-08）修改纪要

1. 【页眉】ctexart 默认页眉显示"当前节名 + 页码" → 导言区加 `\pagestyle{plain}` 解决（页脚居中页码保留）。
2. 【图字号】18 张图全部按"显示宽度匹配"重渲染（figsize≈5.4–5.8 in、dpi=200/220、base 12–13pt），重跑 `程序/数据预处理-可视化.py` / `程序/问题一-可视化.py`（秒级） + `程序/问题二-problem2.py` / `程序/问题三-problem3.py` / `程序/问题四-problem4.py`（分钟级）。
3. 【特殊值表注】负值/0 值/负 R² 全部加 `*` 与表注（表 6、表 7、附表 B4/B5/B6/B7），编译后文本逐页核对渲染成功。
4. 【新发现坑】matplotlib `bbox_inches="tight"` + `constrained_layout=True` 组合会触发 "axes sizes collapsed to zero" 警告并把输出画布放大（实测 5.8in → 9.9in），导致图内文字更小。
   教训：**禁用 bbox\_inches='tight'**，用 `fig.savefig(path, dpi=...)` 固定 figsize×dpi 输出；白边由 LaTeX 图宽吸收。
5. 【重跑核对】p2/p3/p4 脚本重跑后，用 outputs 的 csv 与论文正文逐项核对：p3 三方案合计与分区、p4 七场景（1.44/15.48/18/−429.7/7.1 等）、p2（0.71 万元/6.79 吨/8 迁移/块级 gap=0），全部零漂移。
6. **教训清单**：
   - 先建"显示宽度→figsize"映射表再画图，勿用 15 英寸以上大画布
   - 图内文字最终 pt = matplotlib 字号 ×（显示宽 ÷ 图物理宽），务必令 图物理宽 ≈ 显示宽
   - 参数名/负值/0 值在表格中要统一口径并注解
   - PDF 每页顶部出现"节名+页码"= 默认 headings 页眉，直接 `\pagestyle{plain}`
   - 改脚本后重跑必须做"论文数字↔csv"一致性核对（数据固定时零漂移才可确认无害）
