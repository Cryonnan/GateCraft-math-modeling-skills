# 1. 章节目录（国奖标配，按此顺序）

```text
摘要 + 关键词（第1页）
一、问题重述
    1.1 问题背景（2-3句，引出价值与痛点）
    1.2 题目信息（把题干关键条款 bullet 化：数据形式、已知条件、隐含约束）
    1.3 待求解问题 + 总体技术路线图（问题一~问题四各 1 句复述；图含四问方法链与传递物，见 3.7）
二、模型的假设（4-6 条，每条 1 句，必须"可辩护"：短期性/无竞争/数据可信等）
三、问题分析（总览段 + 每问 3 层递进：先"要做什么"，再"难点是什么"，最后"用什么方法+怎么检验"）
四、符号说明（表格：符号 | 含义 | 单位）
五、数据收集与预处理（筛选 → 清洗 → 特征工程 → 初步可视化 EDA；先诊断后建模的证据在此产出，见 3.8）
六~九、问题一~四：每问固定七段式（C023 实测）
    x.1 问题分析（含每问流程图，见 3.7）
    x.2 数据预处理（先诊断：描述统计/诊断图 → 诊断结论决定模型形式）
    x.3 模型建立（变量处理理由 → 模型结构 → 候选模型对比表 → 事前遴选准则 → 选定）
    x.4 模型求解（Step1-N 算法步骤）
    x.5 结果可视化（图上带阈值线/置信带，见 5 节）
    x.6 检验 / 敏感性（显著性+LR / 参数网格扰动表）
    x.7 结论（编号 3-5 条、每条带数值，独立成节）
十、模型的灵敏度分析（或并入问题末；C023 为每问内嵌式，二者取一但必须闭环）
十一、模型的评价与推广（优点3点、缺点2点、推广1段，不写空话）
参考文献
九（末章）、AI 使用记录（合规披露：工具名+用途；未使用则写"未使用 AI 技术"；正文禁现工具名，见 3.6）
附录 A 支撑材料文件列表（文件名|类型|功能）
附录 B+ 补充结果表格/图表（含诊断图组，如小提琴图）
附录 最后：完整代码（lstlisting）
```

**要点**：全文图表**连续编号**（表1…表N、图1…图N，无论几章；图/表前缀分离，禁"图表N"混用）；每问七段结构完全一致，评委可快速定位；正文页数按赛题要求硬约束（国赛 ≤20 页、华数杯 ≤30 页），附录代码可长（C023 正文 24 页+附录 97 页）。

# 2. 摘要写法（国奖实证 4 段式）

```
[背景段 2 句]：一句话点明研究对象与痛点（如"现有方案忽略个体差异；时点过早检测失败率升高，过晚有安全风险"）
 [问题一&二各一段] 方法 → 结果（【必须带具体数值】：R²、AUC、误差率、收益金额、p 值等）
 [问题三&四各一段] 同上
 [可选灵敏度段 1 句] 对参数扰动的稳定性结论（2024 国奖专设：'波动对总利润影响较小，模型稳健'）
关键词：4-6 个，空格分隔（不写"关键词："后用分号；国奖用空格）
```

铁律：
- 数字驱动：每问结果必须 ≥1 个具体数值（对比"显著提升" vs "提升 17.2%"，后者完胜）
- 每问 2-3 句、总 550-750 汉字，不超 1 页
- 参考用词"针对问题一，…首先…进而… 结果显示…"（2025C 国奖：问题4 甚至写了准确率 99.7%+独立验证误差 <1.5%）
- 缩写首次出现给出全称 + 括号缩写（NIPT 等）

# 3. 问题的分析+建模+检验 三件套

## 3.1 问题分析（每问 1 段，3 层递进）
```
题干要什么 →（转折出）难点/坑（数据稀疏、重复测量、类别不平衡…）→（因此）用什么工具+为何合适 →（并配）什么检验自证有效
```
（范例："鉴于数据存在重复测量与层次结构，选择线性混合效应模型(LMM)+REML，并以 AIC/BIC 比较模型、检验正态性"）

## 3.2 模型建立（正文公式）
- 每个变量的定义先给符号表（符号 | 说明 | 单位），公式给 (编号)、变量下标规范
- 引入约束/推广/扩展时依次罗列公式(3)(4)(5)…
- 多说"为什么这模型"：1-2 句立足问题特性，不罗列教科书
- 方案比选（对比表）：| 方法 | 适用 | 优点 | 缺点 | 本文选择 |

## 3.3 模型检验/诊断（国奖最重要特色，无检验不入围）
三篇国奖全覆盖的"检验四件套"：
1. **模型对比**：对数似然值、AIC、BIC 表（直接"对数似然 2171.44 → 2547.57，+376"）
2. **检验统计量**：LR(χ²) 或 Wald，给出 χ² 值与 p 值（"χ²(1)=752.27, p<0.001 ↑納入随机效应必要性"）
3. **方差分解**：给出 σ_u²/σ_e²、计算 ICC=σ_u²/(σ_u²+σ_e²)=0.743 并解释（"74.3% 变异来自组间、普通回归会低估 SE"）
4. **假设诊断图**：Q-Q 图 + 直方图（正态性）+ 残差 vs 拟合（同方差）+ 偏相关、Fisher 精确检验（分类交叉）

（"检验三题"写法更多见 2023 蔬菜篇；回归类 → 2024 种植篇有 Spearman 相关；机器学习类 → 2025 加排列特征重要性/剩余重要性 — 一)。）

## 3.5 衔接写作的四项要求（工作流检查项，非句式模板）

> 论文句子必须由阶段报告的事实推导（competition-workflow 阶段 0.5/1/2 报告先行）；范文原句只作样本，禁止照搬句式。每项按"要求 / 判定标准 / 正面样本 / 反例"执行，通过与否以判定标准为准。

### R1 定位陈述（每问开头）
- **要求**：每问开头陈述与前问在模型层面的事实差异：①共享构件（决策变量/公式/参数）；②新增或改变的构件；③改变原因（题目新增条件 / 变量类型 / 数据规模 / 口径）。两问同构则显式声明复用。
- **判定标准**：对两问的决策变量集、约束集、目标函数做集合差，开头段必须覆盖全部差异项；漏一项即不通过。
- **正面样本**：2023C 问题三开头（p24）——"同样是最优化问题……但受到单品总数与最小陈列量限制……决策变量由连续型变为混合型，两问需选择不同的优化算法"。
- **反例**：2026 华数杯 7.1 开头直接定义 5 万任务与决策变量，未先声明与问题一（仅决策开工时段、限最后 24 小时）的差异；其 9.1 部分达标（"与问题三的关键区别在于：设施负荷不再由题目给定"）。

### R2 选型依据（每个主要模型）
- **要求**：每个主要模型的选型依据至少满足其一：①数据结构证据（指明哪条数据发现推出该设计）；②对比证据（候选模型实测比较并报指标差异）。
- **判定标准**：对每个模型问"为什么是它、为什么不是最简备选"，正文能答且指向数据或实验即通过；出现"本文采用 X 模型"且无依据即不通过。
- **正面样本**：2023C LSTM 选型给出对比证据（ARIMA/岭回归/灰色预测效果较差→LSTM；瑕疵：未报对比数值）；2026 华数杯问题分析章给出数据结构证据（白噪声检验→分解预测结构）。
- **反例**：2026 华数杯选型依据全前置在问题分析章，正文建模节开头未重述（衔接瑕疵）；2023C 试错对比未报数值（严谨性瑕疵）。
- **写法分工**：问题分析章给选型结论，正文建模节开头用 1-2 句重述动机；候选比选表（| 方法 | 适用 | 优点 | 缺点 | 本文选择 |）置于正文建模节。

### R3 结果解释闭环（每个关键结果）
- **要求**：每个关键结果依次给出：①数值；②机制解释（为什么是这个数）；③外部一致性核验（常识 / 理论预期 / 独立口径基准）。
- **判定标准**：逐条检查关键结果表，三段缺一即不通过。
- **正面样本**：2023C 七日收益（p22）——数值 1745~1810 元 → 机制 → 历史日利润集中于 500~2000 元、七月初约 1000~1500 元的对照。
- **反例**：2026 华数杯问题三碳排 204.5 万吨→62.3 吨的数量级跳变（表8-1），机制（新能源利用率 32.7%→68.8%、购电小时清零、生命周期碳排仅 7.65 吨）分散于后页且未显式点明"该数量级合理"。
- **铁律**：数量级突变/反直觉结果必须紧跟结果显式解释机制。

### R4 构件复用声明（跨问）
- **要求**：跨问复用的符号、公式、参数必须显式声明复用；符号定义全篇唯一；新增构件与复用构件可区分。
- **判定标准**：符号表 + 公式编号审计：每个符号定义唯一；每处跨问引用有显式指认。
- **正面样本**：2023C"本问同样采用问题二中的公式 7"（p24）；2026 华数杯"参数承袭问题二与问题三"（p24）。
- **反例**：两篇均基本达标，未见明确违规项。

优化类求解与验证决策表见 `../../assets/optimization-playbook.md`。

## 3.6 严谨性用语规范
- **主张分级**：每处结论标注证据等级 A=数据复算支持 / B=理论推导支持 / C=定性论证；C 级论证不得写成 A 级事实（如"验证了模型的准确性"须有对应的核验动作与结果）。
- **禁用无依据词**：无数值的"显著提升"、"最优"（未经证明）、"完美"、"完全一致"（除非有逐项核对记录）。
- **数量级突变规则**：跨数量级的结果必须紧跟机制解释并对照独立口径（同 R3）。
- **范围声明**：分析/复算类内容必须写明覆盖范围与未覆盖项（如"未复算数值"）。
- **摘要↔正文↔表格三方对账**：摘要每个数字必须能映射到正文某张表；改写摘要禁止产生新数字。判定：零孤例。反例：大湾区杯摘要"现金25%/短期国债35%/1.87%收益"与正文方案（现金2%/国债0%/16.66%）完全无关，且摘要把 USDT/USDC 风险评分写反。
- **表内列间数学自洽**：同表各列若存在数学关系必须成立（λ↔半衰期=ln2/λ、权重和=1、增长率↔基期、CAGR↔份额）。判定：逐列验算。反例：泰迪杯表7-4 λ=0.010 对应半衰期应为 69.3 天，表内却写"9.3 天"。
- **AI 痕迹规范**：正文禁止出现工具名/模型名标注（如"[GPT-5, OpenAI 计算得到]"）；引用的模型名必须真实发布；统一在附录"AI 使用记录"披露（C023"未使用 AI 技术"亦是合规披露）。判定：grep GPT/DeepSeek/Claude/Qwen/Kimi 等词，正文命中即不通过。
- **方法-样本量匹配**：n=2 时 Min-Max 归一化退化为 0/1，禁止在 n<5 上使用熵权/CRITIC 赋权；混淆矩阵必须披露样本数，正类 <20 时禁止上报 AUC/精确率；比例/百分比变量的系数解释必须核对量纲（0.782 vs 0.00782 差 100 倍）。判定：每个表观指标后必须跟样本量。

## 3.7 流程图两层规范（C023 图2/3/7/9/10 实测）

- **第 1 层·总体技术路线图**：四问方法链串联，问题间箭头标注**传递物**（如"浓度模型→达标概率 p(t,b)→DP 输入"）；置于"1.3 我们的工作"（C023 图2，p3）。
- **第 2 层·每问流程图**：四阶段骨架恒定——①数据（清洗/分层/决策变量扩展）②模型（目标函数/候选对比）③约束与检验（含领域约束：保障率/单调性/FPR≤1%）④求解与敏感性（DP/网格搜索+灵敏度）；**节点内容必须是本问关键词**（"保障率约束""单调性约束""k=2 聚合"直接进框），禁止空泛步骤词；置于 x.1 问题分析之后；四框与正文四节一一对应（C023 图3/7/9/10，p5/10/15/19）。
- **判定标准**：流程图任一节点文字不能回答"本问做了什么"即不通过；无每问流程图直接不通过。
- **反例**：泰迪杯的防泄露设计（扩展窗口/Purged WF/时间戳锁）全部埋在正文段落、没有变成流程图节点，评委扫读不可见；大湾区杯仅 1 张总体框架图+1 张数据思维导图，缺第 2 层。
- **备注**：方案比选用对比表（见 3.2）呈现，不必画成分支菱形；流程图保持顺序四阶段，避免过度复杂。四阶段节点内容对照表与图型模板见 `../../assets/figure-playbook.md`；规格→drawio/PNG 生成与 OCR 读回复核链路见其第 4 节（无视觉模型也可验收流程图）。

## 3.8 先诊断、后建模

- **要求**：每问建模前必须有一句"诊断结论→模型形式"的因果声明，诊断证据为图或表（热力图/分布图/对比表）。
- **判定标准**：出现"本文采用 X 方法"且前文无诊断依据即不通过。
- **正面样本**：C023 热力图→"非单调→排除简单线性→引入二次项"（p5-6）；表2 MixedLM vs GLM（AIC 712.63 vs 749.92、LR=41.29）→选定 LMM（p7）；附录B 小提琴图三观察（p25）。
- **反例**：大湾区杯问题一"本文采用 AHP-熵权-CRITIC-PCA 组合赋权"——先宣布方法后补数据。

# 4. 灵敏度 / 稳健性分析
```latex
\section{模型的灵敏度分析}   % 或并入问题末
调参方式：±5% / ±10% / 扰动成本区间；
呈现：表格（参数取值 | 关键输出（利润/准确率）| 变化率）+ 1-2 句结论
落点："参数波动对目标影响较小 / 结果保持稳定 → 模型稳健"
```
2024 国奖：动态调参 4 个不确定参数后 "总利润与问题三中差距极小，模型稳健" —— 这句必须写，评委定拿分点。

# 5. 图表与表格规范
- 表格：三线表（顶/中/底横线），列宽紧凑，数字对齐；表题在表上、中文；表内列给出单位
- 图形：双幅子图（散点+拟合 / 箱线+残差）；热力图(相关性)；画布分辨率 ≥300dpi；坐标轴中文 + 单位
- 图题在图下、必须有图表编号且正文先引后出（凡引必见图）
- 数量参考：国奖正文 12-30 图、15-30 表（2023 篇 24 表+多图；2024 篇 32 图+若干表）

# 6. 附录（国奖标配三件套）
```
附录 A 支撑材料文件列表（文件名 | 类型 | 说明）
附录 B 主要结果补充表（分日/分年明细 2-10 表；预测结果图 2-10 张）
附录 C 完整代码（统一 lstlisting，保持行号可读，补充绘图代码也可）
```
三篇国奖均含：A 文件清单；B 结果明细列 3 倍于正文的表；C 全部 Python（含可视化、统计检验）与 Stata 代码（如编号）。

## 7. 国检送达清单（写完后逐项打钩）
- [ ] 摘要 ≤1 页，含 ≥1 个数值指标/问
