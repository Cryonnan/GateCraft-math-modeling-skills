- **本 skill 只写内容**：结构、摘要、正文表述、统计结果报告、模型对比、严谨性审查、页数预算。

```

二、问题分析                    2页

五、数据预处理                  1.5页
六~九、四个问题(各4.5页)       18页
十、灵敏度分析                  1.5页
十一、模型评价与推广            1页
十二、结论                      1页
参考文献                        0.5页
══════════════════════════════════
正文总计                        ≤30页
```
**增新必删旧**：新增每个缺失项必须从现有正文等量删除。删减优先级：重复描述 > 过度展开案例 > 冗余特征列表 > 啰嗦学术化表述。

# 官方内容规范（来自 official-paper-format.md，写作红线）

1. **摘要三段论**：起始段（背景+研究问题，2-3 行）→ 主体段（每问一段：问题简化→数学归类→建模思想→算法→模型特点→主要结果[定量]）→ 推广段（推广+灵敏度一句）。禁表格/公式/图；≤1 页；关键词 3-5 个（问题词+模型词+算法词）。
2. **题目命名三式**：直接复制 / 「基于主模型的 原题」/ 谐音梗（不推荐）。
3. **问题重述**（≤1 页）：三部分（背景+需解决问题+现有研究方法）；自组织词句不整段照抄；不引用原题图表；时间紧先拷贝后修改（但不能不改）。
4. **问题分析（红线）**：**绝不能出现结果**（结果只在摘要和求解部分；摘要≈问题分析+结果）；每问回答三问（要做什么/目标/怎么做）；对附件做数据分析；可含思路导图。
5. **模型假设 4-8 条**：三来源（题目自带/题目推得/模型需要）；禁"模型正确性"类假设；每条在正文建模处被引用。
6. **符号说明**：三线表三栏（符号|符号说明|单位）、约半页、不换页、不参与一般表格编号；只用一次的符号不必列。
7. **每问三段式**：模型建立→求解→检验；每问必须有检验/验证闭环（滚动验证、小规模精确对照、独立复算等）。
8. **模型总结**：优点 5-7 条突出亮点、缺点真实（=改进方向）、推广半页。
9. **参考文献**（≥5 篇、另起一页）：书/刊/网三种格式（详见 official-paper-format.md 十四），正文标注 [编号]，只引真实文献。
10. **AI 声明**：正文后、参考文献前；两套措辞（未使用/使用了+用途+详见附录）。

# 操作 2：摘要重写（≤500 字，最后写）

```
【背景1-2句】→ 针对问题一(方法+结果1句) → 问题二(方法+结果1句)
→ 问题三(方法+结果1句) → 问题四(方法+结果1句)
→ 本文创新点在于：①②③（各1句）

```
规则：方法+精确数值结果（"提升 17.2%"优于"显著提升"）；每问 2-3 句；不回避缺点不夸大优点；摘要数值必须与正文/报告一致（摘要最后写、从正文复制数值）。

# 学术写作规范（统计学博士审校）

## 段落与句式
- **严禁 bullet points**：正文不得用"•""●""-"符号，必须转连贯段落（排版层的技术路线清单除外）。
- 段落 3-5 句/段、≤150 字、一段一个完整论点；段间用过渡词连接。

## 过渡连接词表
| 关系 | 论文可用词 |
|------|-----------|
| 递进 | 在此基础上、进一步地、此外、不仅如此 |
| 因果 | 因此、由此、鉴于此、从而、进而 |
| 转折 | 然而、但是、尽管如此、与此相对 |
| 列举 | 其一…其二…、首先…其次…最后 |
| 总结 | 综上、概括而言、上述结果表明、总体来看 |

## 语态与时态
- 全程被动语态：✅"本文构建了非对称XGBoost" ❌"我们构建了"。
- 建模过程过去时（"本文采用 Corrado 秩检验，结果表明…"）；普遍规律/结论现在时；图表引用现在时（"如表X所示"）。

## 图表分析三段式（每图 ≥3 行）
描述（客观数据特征）→ 解读（机制/原因）→ 结论（建模选择/理论启示）。图表出现前后必须有引导和解释，禁连续堆图。

## 统计结果报告规范（每个数值结果三要素）
```
1. 效应量：点估计（CAR=-0.57%、Rank IC=0.192）
2. 不确定度：标准误、置信区间、p 值
3. 实质性解读：这个效应在业务上意味着什么
```
正确模板："CAR 在[-3,+3]窗口内均值为-0.57%（95%CI: [-0.63%, -0.51%]），Corrado Z=-166.54，p<0.001。扣除 0.50% 双边摩擦成本后净 CAR 为-0.07%，表明全样本事件不具备可交易的经济价值。"
严禁：❌"p<0.05，显著"（无效应量）；❌"模型效果很好"（无量化）；❌"这回答了问题X的要求"（刻意点题）。

## 业务解释自然融入
结论→证据→理论顺序："CAR 显著为负（均值-0.57%，Corrado Z=-166.54，p<0.001），与代理成本理论预期一致——高比例质押触发投资者对公司治理风险的规避行为。"

# 数学建模严谨性审查（每个建模决策回答三问）

1. **为什么选这个模型？** → 模型对比表（AIC/RMSE/p 值对比替代方案）
2. **假设条件是否满足？** → 诊断检验（正态/异方差/自相关/VIF）——交 `statistical-diagnosis` 出 DIAGNOSIS_REPORT.md
3. **结论对模型选择的敏感度？** → 灵敏度分析（改参数/改方法）——交 `sensitivity-analysis` 出 SENSITIVITY_REPORT.md

## 常见统计谬误及规避
| 谬误 | 表现形式 | 规避方法 |
|------|---------|---------|
| 大样本谬误 | N=200,000 时 p 总是 <0.001 | 报告效应量+经济显著性阈值 |
| 多重比较 | 同时检验 8 类事件不校正 | BH-FDR 或 Bonferroni |
| 数据窥探 | 全样本筛选特征再交叉验证 | Purged WF CV 严格时序分割 |
| 幸存者偏差 | 只用沪深300回测 | 明确样本范围，讨论外推局限 |
| p-hacking | 试多个 θ 直到显著 | 预设搜索范围，报告全部结果 |

## 公式书写规范
- 变量首次出现即定义（符号+含义+单位）；全文统一连续编号，不按章重编。
- 复杂公式分层拆解（基础层→中间层→输出层，每层独立编号）；引用写"式(X)"而非"公式(X)"。

## 算法步骤书写规范
```
Step1: [名称] — [具体操作]
Step2: [名称] — [具体操作]
复杂度：O(...)或迭代次数上限
⚠ 禁止只写"本文使用SLSQP求解"，必须写输入→目标函数→约束→输出
```

# 华数杯/国赛内容范式（2026 实战沉淀，详见 huashubei-writing-guide.md）

- **结果数字一条链（可复现性铁律）**：附件数据 → 程序输出 → 论文数字 → 附录复算，全程可复现可核对；改脚本重跑必须做「论文数字↔csv」一致性核对，零漂移才确认无害。
- **章节红线**：问题重述自组织词句≤1 页；问题分析禁结果；模型假设三来源；符号说明三栏表；每问三段式必有检验闭环。
- **特殊值表注**：负值/0 值/负 R²/恒定量必须加 * 与表注（表注措辞见 guide 2.2）。
- **AI 声明**：正文后、参考文献前。
