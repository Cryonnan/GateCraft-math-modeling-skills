# 回归分析作业助手

## 快速开始
1. 输入 `/linear-regression-hw` 或描述"回归分析作业"
2. 提供数据（复制粘贴或发送文件）
3. 自动完成完整分析

## 支持类型
- **一元线性回归**：1个自变量 + 1个因变量
- **多元线性回归**：多个自变量 + 1个因变量

## 一元线性回归输出
- 散点图 + 线性趋势判断
- 回归方程 + 显著性检验
- 拟合优度(R²)
- 残差诊断
- 外推预测判断

## 多元线性回归输出
- 回归方程
- 各变量显著性（p < 0.05）
- 标准化系数排序（作用大小）
- 模型拟合效果

## 核心R函数
| 函数 | 用途 |
|------|------|
| `lm(y ~ x)` | 一元回归 |
| `lm(y ~ x1 + x2 + x3)` | 多元回归 |
| `summary()` | 模型摘要 |
| `rstandard()` | 学生化残差 |
| `predict()` | 预测新值 |
| `scale()` | 数据标准化 |
