## 第一步：题型自适应分发（先读题，再选方案——不要套模板）

先拿到题面与阶段 2 的 RESULTS_REPORT.md（若有），判断题型，再选方案：

| 题型 | 灵敏度问题是什么 | 首选方案 | 报告重点 |
|------|------------------|----------|----------|
| 优化类 | 最优解对目标系数/约束右端/关键参数的稳定性 | 单因素 ±扰动（±5%/±10%/±20%）+ 弹性系数；约束右端扰动看最优解是否质变 | 目标值变化率、方案是否翻转、影子价格 |
| 预测类 | 预测对关键假设/初始条件/外推幅度的敏感度 | 假设漂移实验 + 外推区间检验 | 预测曲线漂移幅度、外推风险声明 |
| 评价类 | 排名对权重/指标增减/归一化方式的敏感度 | 权重 ±10% 扰动看排名翻转；指标增删实验 | 排名稳定性、翻转临界权重 |
| 机理/动力学类 | 参数扰动下系统行为变化 + 数值可信度 | 参数 ±% 扫描 + 守恒量/步长收敛检查 | 守恒量漂移、步长收敛、相图变化 |
| 概率/仿真类 | 分布参数不确定性如何传播 | 蒙特卡洛 + BCa CI | 均值/分位数/置信区间、参数贡献 |
| 事件研究/金融类 | θ/窗口/半衰期等策略参数 | 下方「事件研究类模板」（θ 模板只在这里用） | Rank IC/收益/回撤随参数变化 |

**参数数量决定方法层**（所有题型通用）：
```
k ≤ 5   → 单因素逐个扫描（每参数 ≥3 个点，如 ±10%/+20%/-20%）
5 < k ≤ 20 → Morris 筛选（μ* 排序）
k > 20  → Morris 初筛 → top5 → Sobol 精细
```

## 全局准则

**准则1：灵敏度分析 ≠ 参数试一圈。** 只改参数不量化重要性排序 = 不及格。必须给出重要性排序（μ* 或 S1）及不确定度。
**准则2：必须声明假设与局限。** 每个方法输出附：假设（如 Sobol 要求参数独立、Morris 要求近似单调）+ 局限（Morris 只筛查不量化、Sobol 需 n×(2k+2) 次调用）。
**准则3：结论要落回业务。** 只说"稳健"不合格，必须写"参数 ±10% 时总利润变化 <X%，方案不翻转，模型稳健"（2024 国奖原句式）。
**准则4：产出 SENSITIVITY_REPORT.md。** 论文阶段引用数值只能来自本报告；改脚本重跑后必须与论文数字核对零漂移。

# 方法工具箱

## Level 1：单因素灵敏度（k≤5 首选）

弹性系数：`ε = (ΔY/Y₀) / (Δθ/θ₀)`——θ 变化 1% 时 Y 变化 ε%。

报告模板（每参数 ≥3 个点）：
```markdown
| 参数 | 基准值 | -20%时Y | +20%时Y | 弹性系数ε | 敏感度 |
|------|--------|---------|---------|-----------|--------|
| θ | 1.10 | 0.156 | 0.171 | 0.48 | 中 |
```

## Level 2：Morris 筛选（5<k≤20 首选）

```python
from SALib.sample import morris
from SALib.analyze import morris as morris_analyze
def morris_sensitivity(problem, model_func, n_samples=100):
    param_values = morris.sample(problem, n_samples)
    Y = np.array([model_func(x) for x in param_values])
    return morris_analyze.analyze(problem, param_values, Y)
# 重要性排序看 μ*；σ/μ* > 1 → 强非线性/交互
```
**局限声明（论文必写）**：Morris 只给相对排序，μ* 不具有方差分解的定量含义；要精确贡献比例用 Sobol。

## Level 3：Sobol 全局（需收敛诊断）

```python
# 收敛诊断必须执行：S1 的 95%CI 宽度 < 0.05 才算收敛
for n in [128, 256, 512, 1024]:
    Si = sobol.analyze(problem, Y[:n*(2*k+2)])
    print(f"N={n}: S1_max={Si['S1'].max():.4f}, CI={Si['S1_conf'].max():.4f}")
```
解读：S1=独立贡献、ST=含交互总贡献、ST−S1 大→主要通过交互起作用、ΣS1<1→存在交互。
**假设声明**：参数间相互独立；若实际相关，Sobol 结果需谨慎解读。

# 竞赛模板（按题型取用）

## 模板 A：优化类（华数杯 2026 C 题实测版）
```markdown
| 扰动场景 | 关键参数扰动 | 总成本/总利润变化 | 弹性系数 | 方案是否翻转 |
|----------|--------------|-------------------|----------|--------------|
| 场景1 | 购电价 +10% | ... | ... | 否 |
| ...   | ... | ... | ... | ... |
| 场景7 | ... | ... | ... | 否 |
结论：参数 ±10% 扰动下，总利润变化 <X%，弹性系数最大 0.948（<1 弱敏感），七场景方案均不翻转 → 模型稳健。
```
- 实测做法：±10% 扰动 + 弹性系数 + 七场景；优化题额外做约束右端项扰动，报告最优解是否质变。
- 落点句式："参数波动对目标影响较小 / 结果保持稳定 → 模型稳健"（评委拿分句，2024 国奖原句）。

## 模板 B：评价类（权重扰动 + 排名翻转）
```markdown
| 指标 | 权重基准 | 权重+10%后前3名 | 权重-10%后前3名 | 翻转临界权重 |
|------|----------|-----------------|-----------------|--------------|
| 成本 | 0.30 | A,B,C | A,C,B | 0.34 |
结论：权重 ±10% 内前 3 名不变（或成本权重 >0.34 时 B/C 互换），排名基本稳健。
```
